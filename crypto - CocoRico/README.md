# CocoRiCo

**Category:** ![](https://img.shields.io/badge/crypto-3776AB)

**Difficulty:** ⭐

**Description:** The challenge provides an authentication system based on symmetric encryption and a CRC-based integrity tag. A token is issued upon registration and can be reused to log in.

- The source code is provided in `cocorico.py`
- The code is running at: `nc chall.fcsc.fr 2150`

**Goal:** Forge the admin token to log in and get the flag.

# TL;DR

The challenge uses AES in OFB mode (a stream cipher) along with CRC32 for integrity. Since the ciphertext is just the plaintext XORed with the keystream, and the CRC32 is predictable, it's possible to forge an admin token by extracting the keystream and re-encrypting a tampered payload.

# Solution

### Analyzing the cryptosystem

Upon registration, when we input a new username, we are given a token allowing us to log in. The token is generated by appending a CRC32 tag to the JSON payload and encrypting it using AES in OFB mode.

```python
from zlib import crc32 as le_mac

	return AES.new(self.la_clef, AES.MODE_OFB, iv = b"\x00" * 16)

def chiffrer_integre(self, le_message):
	le_tag = int.to_bytes(le_mac(le_message), 4)
	return self.le_chiffrement().encrypt(le_message + le_tag)
```

At login, when we provide a token, it is decrypted, checked for CRC32 integrity, and parsed as JSON. if `name` is `toto`and `admin` is `True`, we get the flag:

```python
def dechiffrer(self, le_chiffre):
	x = self.le_chiffrement().decrypt(le_chiffre)
	le_message, t = x[:-4], x[-4:]
	le_tag = int.to_bytes(le_mac(le_message), 4)
	if le_tag == t:
		return le_message
	else:
		return b""
```

**AES-OFB is a stream cipher,** so encryption is just: `ciphertext = plaintext ⊕ keystream`

### Attack plan

1. Connect to the server and register with known data (e.g. `{"name": "aaaa", "admin": False}`), then save the token.
2. Compute the CRC32 of the plaintext, append it to the JSON, and XOR the result with the token to extract the full keystream:
`keystream = token_aaaa ⊕ (plaintext_aaaa || crc_aaaa)`
3. Forge a new plaintext payload for toto: `{"name": "toto", "admin": True}`
4. Recompute the CRC32, append it, XOR with the keystream to obtain a valid admin token:
`token_admin = (plaintext_admin || crc_admin) ⊕ keystream`
5. Log in with the admin token and get the flag

# Remeditation

- Never use CRC32 as an integrity mechanism, as it is vulnerable to tampering.
- Never use AES in stream mode (e.g. OFB/CTR) without **MAC authentication**, or use proper AEAD modes like AES-GCM.
